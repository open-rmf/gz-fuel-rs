# gz-fuel client for Rust

A library for interacting with the  [gz-fuel](https://github.com/gazebosim/gz-fuel-tools) REST API over Rust. Use this to
* Update your gz-fuel model cache
* Fetch models from the [Gazebo App](https://app.gazebosim.org/dashboard)

This crate comes with an executable that performs an update of your local gz-fuel cache.
